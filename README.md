\\# Lloyd Employee Management System







A web-based Employee Management System developed using ReactJS, Ant Design, ExpressJS, and Microsoft SQL Server.







\\## Features







\\- User login functionality



\\- View employee records



\\- Add new employees



\\- Edit employee information



\\- Delete employee records



\\- Automatic employee number generation



\\- Employee report generation



\\- RESTful API



\\- Microsoft SQL Server database







\\## Technologies Used







\\### Frontend



\\- ReactJS



\\- Ant Design



\\- Vite







\\### Backend



\\- Node.js



\\- ExpressJS



\\- ODBC



\\- RESTful API







\\### Database



\\- Microsoft SQL Server



\\- LocalDB
